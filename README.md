# Campus Navigation System

## Project Overview

This project has been designed as a team final project for CS300 course at Southeast Missouri State University.

Our main objective was to develop an application that provides users with information on the shortest path between two buildings on the campus. We have developed an interactive map based on the use of Java and JavaFX.
## Features

- Interactive campus map displaying buildings and pathways
- Select starting and destination buildings
- Find the shortest route using Dijkstra's algorithm
- Highlight the calculated route on the map
- Display total distance and estimated walking time
- Load building and pathway information from CSV files

## Technologies Used

- Java
- JavaFX
- Dijkstra's Algorithm
- Graph Data Structures
- CSV File I/O

## Project Structure

- `src/main/app/` – Main application and user interface
- `src/main/algorithm/` – Dijkstra's shortest-path algorithm
- `src/main/model/` – Graph, Node, and Edge classes
- `src/main/io/` – CSV data loading
- `src/main/resources/` – Campus map image
- `data/` – Campus building and pathway data

## How to Run

1. Install JDK 19 and JavaFX 21.
2. Open the project in a compatible Java IDE.
3. Configure the JavaFX SDK.
4. Run `MainApp.java`.
5. Select the starting and destination buildings to find a route.
